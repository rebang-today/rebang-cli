今日热榜 CLI

今日热榜（rebang.today）官方命令行客户端：在终端里浏览微博、知乎、B 站、GitHub 等平台的热榜，搜索热点，阅读 AI 总结；输出 JSON，也能交给 Claude Code、Codex 等 AI Agent 使用。

$ rebang list --tab weibo -n 5
#标题热度链接
1示例热搜标题一235.6万https://s.weibo.com/…
2示例热搜标题二181.2万https://s.weibo.com/…
3示例热搜标题三96.4万https://s.weibo.com/…
4示例热搜标题四72.0万https://s.weibo.com/…
5示例热搜标题五58.9万https://s.weibo.com/…
用浏览器打开第 N 条：rebang open N --tab weibo
$ rebang list --tab zhihu -n 1 -o json | jq '.items[0] | {rank, title, item_key}'
{ "rank": 1, "title": "示例问题标题", "item_key": "…" }

示意内容，实际以实时热榜为准。不带参数运行 rebang 进入全屏交互界面，支持键盘与鼠标。

安装

curl -fsSL https://cli.rebang.today/install.sh | sh

默认安装到 ~/.local/bin/rebang；不在 PATH 中时脚本会提示需要加入的那一行。

irm https://cli.rebang.today/install.ps1 | iex

在 PowerShell 中运行。安装到 %LOCALAPPDATA%\Programs\rebang 并加入用户 PATH，重新打开终端后生效。

brew install rebang-today/tap/rebang

适用于 macOS。升级用 brew upgrade rebang。

同时安装 Agent Skill

安装脚本检测到本机装有 Claude Code、Codex（存在 ~/.claude、~/.codex 或 ~/.agents）时，会询问“是否安装 rebang Agent Skill？[Y/n]”，直接回车即安装；没有终端可询问时（CI 等）不安装。也可以明确指定：

curl -fsSL https://cli.rebang.today/install.sh | sh -s -- --with-skill   # 或 --no-skill
环境变量说明
REBANG_INSTALL_SKILL1 同时安装 Agent Skill，0 不安装，均不再询问
REBANG_INSTALL_DIR安装目录
REBANG_VERSION安装指定版本，如 0.1.0

Windows 可先设置 $env:REBANG_INSTALL_SKILL=1 再运行安装命令。安装脚本会校验安装包的 sha256。

快速上手

rebang                          # 进入交互界面
rebang list --tab zhihu         # 知乎热榜
rebang list --tab weibo -n 10   # 微博热搜前 10 条
rebang search 大模型            # 搜索热榜条目
rebang summary <item_key>       # 条目的 AI 总结（item_key 来自 -o json）
rebang menus                    # 菜单列表，再用 tabs / nodes 找榜单

JSON 输出

输出到终端时默认是表格，被管道或 Agent 读取时默认 JSON，也可以用 -o json|md|table 指定。结果写标准输出，提示写标准错误，管道里的 JSON 可以直接解析：

rebang list --tab weibo -n 10 | jq -r '.items[] | "\(.rank). \(.title)"'

登录（可选）

热榜、搜索与 AI 总结都不需要登录。需要“我的关注”、内容监控等功能时再登录：

rebang auth login               # 浏览器授权；SSH 等无桌面环境加 --no-browser
rebang following                # 我的关注
rebang monitor hits --unread    # 内容监控中未读的命中内容

每个命令的详细参数见 rebang <命令> --help。

给 AI Agent 使用

rebang 内置一份 Agent Skill，安装后 Claude Code、Codex 等 Agent 就知道如何查热榜、搜索与读取 AI 总结。

rebang skill install            # 安装到本机已有的 Agent
rebang skill install --agent claude
rebang skill status
rebang skill uninstall
随版本同步

Skill 内嵌在程序中，rebang update 升级后自动同步已安装的 Skill。

按需登录

只有遇到需要登录的功能时，Agent 才会询问你，并把授权链接和授权码转告给你。

版本提醒

有新版本时 JSON 结果附带 _notice，Agent 在完成任务后提醒你，不会自行升级。设置 REBANG_NO_NOTICE=1 关闭。

交给 Agent 安装

把下面这段发给你的 Agent：

请帮我安装今日热榜命令行 rebang，并把它的 Agent Skill 装到本机：
1. 运行 curl -fsSL https://cli.rebang.today/install.sh | sh -s -- --with-skill
   （Windows 用 PowerShell：$env:REBANG_INSTALL_SKILL=1; irm https://cli.rebang.today/install.ps1 | iex）
2. 运行 rebang skill install，确认 Skill 已安装（rebang skill status）。
3. 运行 rebang list --tab zhihu -n 5 -o json 验证可用，这一步不需要登录。
不需要登录。以后用到我的关注、内容监控等功能时，再按需帮我登录。

更新与卸载

rebang update            # 升级到最新版本，并同步已安装的 Agent Skill
rebang update --check    # 只检查是否有新版本

通过 Homebrew 安装的请使用 brew upgrade rebang。

卸载

步骤macOS / LinuxWindows
移除 Agent Skillrebang skill uninstall
删除程序rm ~/.local/bin/rebang
Homebrew：brew uninstall rebang		删除 %LOCALAPPDATA%\Programs\rebang
删除配置与凭证（可选）rm -r ~/.config/rebang删除 %AppData%\rebang

删除凭证前可先运行 rebang auth logout，在服务端吊销本机的登录。

校验与安全

  • 版本信息：https://cli.rebang.today/manifest.json，包含最新版本、各平台下载地址与 sha256。
  • 安装包位于 https://cli.rebang.today/v<版本>/，同目录下有 checksums.txt 与每个安装包的 .minisig 签名；也可以从 GitHub Releases 下载。
  • rebang update 会校验 sha256 与 minisign 签名，公钥内置在程序中，ID 为 05B5851321C39815。

手动校验下载的安装包：

minisign -Vm rebang_<版本>_<系统>_<架构>.tar.gz \
  -P RWQVmMMhE4W1BeDo1A9XochNm6l4wkPvqzzVUZdIM4yf9/gEqyg0vG/y
macOS 上用浏览器手动下载的程序可能提示“无法验证开发者”，解压后执行 xattr -d com.apple.quarantine ./rebang 即可；通过安装脚本或 Homebrew 安装不受影响。
