// 能做什么

你提问，Agent 去热榜上找答案。

装好之后不用记任何命令。下面是几种常见的问法，以及 Agent 在背后做的事。

01 · 看热点

今天大家在聊什么

今天微博和知乎都在聊什么？挑五条说说

  • rebang list --tab weibo -n 20
  • rebang list --tab zhihu -n 20
  • rebang summary <item_key>

跨平台合并同一件事，挑出最热的几条，每条附 AI 总结的要点和原链接。

02 · 研究话题

一个话题的来龙去脉

最近一周大家怎么看新能源车降价？

  • rebang search 新能源车 --days 7
  • rebang search 降价 --days 7
  • rebang summary <item_key>

输出一份带来源的简报：上过哪些平台的热榜、发生了什么、各方观点和网友反应。

03 · 盯关键词需登录

我关心的事有没有新动静

我监控的关键词今天有什么新内容？

  • rebang monitor hits --unread
  • rebang summary <item_key>

按监控计划分组汇总新命中的内容。第一次用到时，Agent 会把授权链接发给你确认登录。

更多应用陆续加入：每日热点简报、监控摘要……

// 工作原理

CLI 负责取数，Skill 教 Agent 怎么用。

rebang 命令行连接今日热榜，输出结构化的 JSON；随它一起发布的 Skill 是写给 Agent 的说明书，分成两层。

两层 Skill

手册让 Agent 知道每个命令能做什么；应用把命令组合成一件完整的事，并规定输出格式。

rebang/             # 命令行手册
  SKILL.md          # 调用约定、退出码、权限
  references/       # 浏览 · 搜索 · AI 总结 · 账号 · 监控
rebang-research/    # 应用：话题研究简报
rebang-…/           # 更多应用

一次提问的过程

  1. 你用自然语言提问，Agent 根据 Skill 判断该用哪些命令。
  2. Agent 调用 rebang，拿到榜单、搜索结果和 AI 总结的 JSON。
  3. Agent 筛选、合并、整理，回答里每条都附原链接和查询时间。
  4. 遇到需要登录或会员的功能，Agent 会先问你，不会自作主张。

只引用真实内容

标题、热度和链接都来自命令结果，Skill 要求 Agent 不编造。

按需登录

热榜、搜索、AI 总结都不用登录。用到关注、监控时，Agent 才把授权链接转给你。

随版本同步

rebang update 升级程序时，已安装的 Skill 一起更新。

不擅自升级

有新版本时 Agent 只在回答末尾提醒你，不会自己动手。

让 Agent 安装（推荐）

把这句话发给你的 Agent。它会读取 安装指南，按你的系统装好程序与 Skill，再用一条命令验证。

帮我安装今日热榜 CLI 和 Skill：https://cli.rebang.today/install.md

自己安装

安装程序；检测到本机的 Agent 时会询问是否一并安装 Skill，直接回车即安装。

curl -fsSL https://cli.rebang.today/install.sh | sh
irm https://cli.rebang.today/install.ps1 | iex
brew install rebang-today/tap/rebang

安装到 ~/.local/bin。之后运行 rebang skill install 也可以随时安装 Skill。

在 PowerShell 中运行，安装后重新打开终端即可使用。

Homebrew 只安装程序，之后运行 rebang skill install 安装 Skill。

已经在用 skills 工具或 Claude Code 插件 只装 Skill

用 npx skills 安装到任意支持 Agent Skills 的 Agent：

npx skills add rebang-today/rebang-cli -g

或者在 Claude Code 中通过插件市场安装：

/plugin marketplace add rebang-today/rebang-cli
/plugin install rebang@rebang-today

这两种方式只安装 Skill，第一次使用时 Agent 会按 Skill 的说明安装 rebang 程序。Skill 由对应工具负责更新；不要再用 rebang skill install 重复安装同名 Skill。

安装选项 Agent Skill、安装目录、指定版本

检测到本机有 ~/.claude、~/.codex、~/.agents、~/.cursor 或 ~/.gemini 时，安装脚本会询问是否安装 Agent Skill；没有终端可询问时（如 CI）不安装。也可以明确指定：

curl -fsSL https://cli.rebang.today/install.sh | sh -s -- --with-skill   # 或 --no-skill
环境变量说明
REBANG_INSTALL_SKILL1 安装 Agent Skill，0 不安装，都不再询问
REBANG_INSTALL_DIR安装目录，默认 ~/.local/bin；Windows 默认 %LOCALAPPDATA%\Programs\rebang
REBANG_VERSION安装指定版本，如 0.1.0

Windows 可先设置 $env:REBANG_INSTALL_SKILL=1 再运行安装命令。安装脚本会校验安装包的 sha256。

升级 rebang update 
rebang update            # 升级到最新版本，并同步已安装的 Agent Skill
rebang update --check    # 只检查是否有新版本

通过 Homebrew 安装的请使用 brew upgrade rebang，再运行 rebang skill install 同步 Skill。

卸载 程序、Skill 与本地配置
步骤macOS / LinuxWindows
退出登录（可选）rebang auth logout，让这台设备的登录失效
移除 Agent Skillrebang skill uninstall
删除程序rm ~/.local/bin/rebang
Homebrew：brew uninstall rebang		删除 %LOCALAPPDATA%\Programs\rebang
删除配置与凭证rm -r ~/.config/rebang删除 %AppData%\rebang
校验与安全 sha256、minisign 签名
  • 版本信息：manifest.json，包含最新版本、各平台下载地址与 sha256。
  • 安装包位于 https://cli.rebang.today/v<版本>/，同目录有 checksums.txt 和每个安装包的 .minisig 签名；也可以从 GitHub Releases 下载。
  • rebang update 会校验 sha256 与 minisign 签名，公钥内置在程序中，ID 为 05B5851321C39815。

手动校验下载的安装包：

minisign -Vm rebang_<版本>_<系统>_<架构>.tar.gz \
  -P RWQVmMMhE4W1BeDo1A9XochNm6l4wkPvqzzVUZdIM4yf9/gEqyg0vG/y

macOS 上用浏览器手动下载的程序可能提示“无法验证开发者”，解压后执行 xattr -d com.apple.quarantine ./rebang 即可；通过安装脚本或 Homebrew 安装不受影响。

// 命令行

你自己也可以直接用。

Agent 用的就是这个命令行。在终端里它有交互界面，也适合写进脚本。

交互界面

在终端里刷热榜

不带参数运行，按分类、榜单浏览，预览 AI 总结，支持键盘与鼠标。

$ rebang
↑↓ 移动 ←→ 来源 / 榜单 tab 子榜 / 搜索 ↵ 打开
命令与脚本

结构化输出，接管道

终端里是表格，进管道就是 JSON；退出码区分未登录、需要会员、限流等情况。

$ rebang list --tab weibo -n 10 | jq -r '.items[].title'
$ rebang search 大模型
$ rebang summary <item_key>

全部命令与参数见 GitHub README，或运行 rebang <命令> --help。
