全网热榜，
一行命令直达。

微博、知乎、B 站、GitHub 等 上百个榜单，在终端里浏览、搜索、读 AI 总结。默认输出 JSON，还内置 Agent Skill，Claude Code、Codex 装上就能用。

curl -fsSL https://cli.rebang.today/install.sh | sh
irm https://cli.rebang.today/install.ps1 | iex
brew install rebang-today/tap/rebang

在 PowerShell 中运行，安装后重新打开终端即可使用。

适用于 macOS，之后用 brew upgrade rebang 升级。

// 三种用法

人用、脚本用、Agent 用。

同一个 rebang：直接运行是交互界面；接在管道里自动输出 JSON；装上 Skill，AI Agent 就知道怎么用它。

01 · 交互界面

像看网页一样刷热榜

不带参数运行，进入全屏界面，按菜单、Tab 浏览榜单，支持键盘与鼠标。

$ rebang
↑↓ 移动 ←→ 来源 / 榜单 tab 子榜 / 搜索 ↵ 打开
02 · 命令与脚本

一条命令拿到结构化结果

终端里是表格，进管道就是 JSON，也可以用 -o json|md|table 指定。

$ rebang list --tab zhihu
$ rebang search 大模型
$ rebang summary <item_key>
03 · AI Agent

让 Agent 读懂今天的热点

内置 Agent Skill，装好后直接用自然语言问，Agent 自己去查榜、搜索、读总结。

$ rebang skill install
✓ 已安装到 claude、codex

// Agent Skill

把今日热榜交给你的 Agent。

Skill 告诉 Agent 有哪些命令、怎么找榜单、什么时候需要登录。你只管提问。

今天科技圈在聊什么？挑三条跟我说说
●rebang list --tab top-tech -n 10 -o json
●rebang summary <item_key> -o json
科技热榜今天最受关注的三条：
  1. …… 一句话要点
  2. …… 一句话要点
  3. …… 一句话要点
需要的话我可以展开某一条的 AI 总结和网友观点。

复制给 Agent，让它帮你装好

请帮我安装今日热榜命令行 rebang，并把它的 Agent Skill 装到本机：
1. 运行 curl -fsSL https://cli.rebang.today/install.sh | sh -s -- --with-skill
   （Windows 用 PowerShell：$env:REBANG_INSTALL_SKILL=1; irm https://cli.rebang.today/install.ps1 | iex）
2. 运行 rebang skill install，确认 Skill 已安装（rebang skill status）。
3. 运行 rebang list --tab zhihu -n 5 -o json 验证可用，这一步不需要登录。
不需要登录。以后用到我的关注、内容监控等功能时，再按需帮我登录。
Claude CodeCodex~/.agents/skills 兼容 Agent

随版本同步

Skill 内嵌在程序里，rebang update 升级后自动同步已安装的 Skill。

按需登录

热榜、搜索、AI 总结都不用登录。用到关注、监控时，Agent 才会把授权链接转给你。

不擅自升级

有新版本时 JSON 里附带 _notice，Agent 会提醒你，不会自己动手。

// 命令一览

常用命令

每个命令的完整参数见 rebang <命令> --help。

rebang list

查看榜单，如 --tab weibo -n 10

rebang search

按关键词搜索热榜条目

rebang summary

条目的 AI 总结：要点、经过、观点、网友怎么看

rebang menus

菜单：综合、科技、娱乐、开发、财经…

rebang tabs

菜单下的榜单与二级 Tab，如 --menu tech

rebang open

用浏览器打开第 N 条

rebang following需登录

我关注的榜单

rebang monitor需登录

内容监控的计划与命中内容

rebang auth login

浏览器授权登录，无桌面环境加 --no-browser

rebang skill

安装、查看、卸载 Agent Skill

rebang update

升级到最新版本，校验签名后替换

rebang doctor

环境诊断，排查安装与连接问题

rebang list --tab weibo -n 10 | jq -r '.items[] | "\(.rank). \(.title)"'

结果写标准输出，提示写标准错误；退出码区分未登录（3）、需要会员（4）、限流（5）、网络错误（6）等情况，方便脚本处理。

// 安装说明

安装、升级与卸载

需要指定目录、版本，或者想手动校验安装包，看这里。

安装选项 Agent Skill、安装目录、指定版本

检测到本机有 ~/.claude、~/.codex 或 ~/.agents 时，安装脚本会询问是否安装 Agent Skill，直接回车即安装；没有终端可询问时（如 CI）不安装。也可以明确指定：

curl -fsSL https://cli.rebang.today/install.sh | sh -s -- --with-skill   # 或 --no-skill
环境变量说明
REBANG_INSTALL_SKILL1 安装 Agent Skill，0 不安装，都不再询问
REBANG_INSTALL_DIR安装目录，默认 ~/.local/bin；Windows 默认 %LOCALAPPDATA%\Programs\rebang
REBANG_VERSION安装指定版本，如 0.1.0

Windows 可先设置 $env:REBANG_INSTALL_SKILL=1 再运行安装命令。安装脚本会校验安装包的 sha256。

升级 rebang update 
rebang update            # 升级到最新版本，并同步已安装的 Agent Skill
rebang update --check    # 只检查是否有新版本

通过 Homebrew 安装的请使用 brew upgrade rebang。

卸载 程序、Skill 与本地配置
步骤macOS / LinuxWindows
退出登录（可选）rebang auth logout，在服务端吊销本机的登录
移除 Agent Skillrebang skill uninstall
删除程序rm ~/.local/bin/rebang
Homebrew：brew uninstall rebang		删除 %LOCALAPPDATA%\Programs\rebang
删除配置与凭证rm -r ~/.config/rebang删除 %AppData%\rebang
校验与安全 sha256、minisign 签名
  • 版本信息：manifest.json，包含最新版本、各平台下载地址与 sha256。
  • 安装包位于 https://cli.rebang.today/v<版本>/，同目录有 checksums.txt 和每个安装包的 .minisig 签名；也可以从 GitHub Releases 下载。
  • rebang update 会校验 sha256 与 minisign 签名，公钥内置在程序中，ID 为 05B5851321C39815。

手动校验下载的安装包：

minisign -Vm rebang_<版本>_<系统>_<架构>.tar.gz \
  -P RWQVmMMhE4W1BeDo1A9XochNm6l4wkPvqzzVUZdIM4yf9/gEqyg0vG/y

macOS 上用浏览器手动下载的程序可能提示“无法验证开发者”，解压后执行 xattr -d com.apple.quarantine ./rebang 即可；通过安装脚本或 Homebrew 安装不受影响。
